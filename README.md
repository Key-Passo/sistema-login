# 🔐 Sistema de Login — KeyPasso

## 📌 Sobre o projeto

O Sistema de Login é um dos módulos do KeyPasso, desenvolvido como parte do projeto final da disciplina de Programação Orientada a Objetos (POO).

Sua função é realizar a autenticação do usuário e direcioná-lo para a tela de seleção dos demais módulos da aplicação.

## 🎯 Objetivo

Desenvolver uma tela de login funcional utilizando Java e Swing, aplicando os conceitos de Programação Orientada a Objetos e preparando a integração com os demais módulos do KeyPasso.

## 🖥️ Funcionalidades

- Tela de login;
- Validação das credenciais;
- Tela de seleção;
- Navegação entre as telas;
- Integração futura com a Agenda de Contatos e a Agenda de Anotações.

## 🛠️ Tecnologias

- Java
- Java Swing
- Programação Orientada a Objetos
- Git
- GitHub
